# Tamkin Dashboard 📊

An advanced admin dashboard built with Vue.js.

### ✨ Features
- Modern admin dashboard interface
- Clean and professional UI
- Fully responsive
- Built with Vue.js

---

### 🛠️ Tech Stack
- **Vue.js**
- HTML5 / CSS3
- JavaScript

---

### 🚀 Getting Started

```bash
npm install
npm run serve
npm run build
```
